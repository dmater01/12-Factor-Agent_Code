# 12-Factor Method Skill - Installation Guide

## What This Skill Provides

The **12-Factor Method** skill gives Claude comprehensive knowledge about building production-ready AI agents using the 12-Factor methodology. This includes:

- ✅ Core principles and philosophy of the 12-Factor approach
- ✅ Complete implementation guides with code examples
- ✅ 12-week structured learning path
- ✅ Ready-to-use system prompt templates
- ✅ Deep architectural details and patterns

## Installation

### Option 1: Upload to Claude.ai (Recommended)
1. Download the `12-factor-method.skill` file
2. Go to claude.ai
3. Click on your profile → Settings → Skills
4. Click "Add Skill" or "Upload Skill"
5. Select the `12-factor-method.skill` file
6. The skill will now be available in all your conversations

### Option 2: Add to a Project
1. Open or create a Project in Claude
2. Go to Project Settings → Skills
3. Upload the `12-factor-method.skill` file
4. The skill will be available only within that project
